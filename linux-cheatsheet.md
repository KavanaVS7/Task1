File System Navigation:

cd-->change directory
ls-->list files
pwd-->show current directory

File and Directory Permissions:

chmod 777 filename
chmod +x scripts.sh
sudo chown user filename

Package Management:

apt-->To install,update,remove softwares
dpkg-->Works with .deb files

Networking Commands:

ifconfig-->Shows the IP address
ping-->Checks connectivity between two machines
netstat-->Shows open ports
traceroute-->Shows the path packets take to reach the destination
